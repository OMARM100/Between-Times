# Scripts

هذا هو المجلد الرئيسي لسكربتات لعبة **Between Times | بين الأزمنة**.

## التنظيم

- player/ — سكربتات اللاعب والحركة والكاميرا.
- maze/ — سكربتات إنشاء وإدارة المتاهة.
- puzzles/ — ثوابت ومتغيرات ومنطق الألغاز.
- يمكن إضافة مجلدات أخرى عند ظهور نظام جديد فعليًا.

نحافظ على أسماء الملفات والمجلدات بالإنجليزية لتوافق أدوات Godot وGit، بينما يمكن أن تكون أسماء العقد والمتغيرات والتعليقات داخل المشروع بالعربية.
