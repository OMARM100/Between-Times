# Between Times | بين الأزمنة

Co-op first-person game project.

## Current state
- Engine: Godot prototype
- Milestone: Prototype
- Repository: `OMARM100/Between-Times`
- Development status: project management and level-design foundation are being established.

## Core first-stage concept
The first stage is one large maze-like environment divided into three nested/concentric regions. Each region has its own checkpoint, puzzles, traversal, traps, threats, exploration spaces, and a gateway toward the next region.

The maze is a hybrid of curved/rounded and square/straight geometry. It includes narrow and wide paths, large corridors, halls, rooms, and gameplay spaces rather than only narrow corridors.

## Co-op pillar
Cooperation should be meaningful through distributed information: one player may discover symbols, clues, ciphers, or keys while another is interacting with the corresponding puzzle. Communication and exploration are part of the solution.
